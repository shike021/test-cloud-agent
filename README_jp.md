# Web Arcade · ブラウザーだけで遊べるミニゲーム集

[简体中文](./README.md) · [English](./README_en.md) · 日本語

ランタイム依存ゼロのフロントエンド専用ミニゲーム集です：**ゲームロビー + スネーク + 五目並べ**。ルールはユニットテスト可能なコアモジュールに閉じ込められており、デスクトップでもモバイルでもそのまま遊べます。

[![Deploy to GitHub Pages](https://github.com/shike021/test-cloud-agent/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/shike021/test-cloud-agent/actions/workflows/deploy-pages.yml)

## クイックスタート

Node.js 20.10 以降が必要です（開発ツールチェーンでのみ使用し、ゲーム自体は Node.js に依存しません）。

```bash
git clone https://github.com/shike021/test-cloud-agent.git
cd test-cloud-agent
npm install
npm run dev            # ローカル静的サーバーを起動
```

<http://127.0.0.1:5173/> を開くとゲームロビーに入れます。

> ソースコードはネイティブの ES Modules を使用しています。ブラウザーは `file://` 経由でのモジュール読み込みを許可しないため、HTML ファイルを直接開かずに `npm run dev`（または任意の静的サーバー）からアクセスしてください。

配布可能な静的サイトが必要な場合は `npm run build` を実行してください。成果物は `dist/` に出力され、`npm run preview` でローカルにプレビューできます。

## ゲーム説明

### スネーク · Snake

リアルタイムの 1 人用ゲームです。固定ステップのロジックとフレーム間補間を組み合わせているため、マス単位のカクついた移動ではなく滑らかな連続移動になり、高精細ディスプレイにも対応します。

**操作**

| 操作             | キーボード                             | モバイル                               |
| ---------------- | -------------------------------------- | -------------------------------------- |
| 移動             | `↑` `↓` `←` `→` または `W` `A` `S` `D` | 画面上の方向キー、または盤面のスワイプ |
| 開始 / 一時停止  | `スペース` / `P`                       | 「開始」ボタン、または盤面のタップ     |
| リスタート       | `R` / `Enter`                          | 「リスタート」ボタン                   |
| 効果音の切り替え | `M`                                    | サウンドボタン                         |

**ルール**

- 赤い果実を食べると **10 点**を獲得し、体が 1 節伸びます。
- 通常の果実を 5 個食べるごとに金色の星が出現します。星は **50 点**になりますが体は伸びません。星には制限時間（外周のリング）があり、時間切れで消えます。
- 累計 **60 点**ごとにレベルが上がって移動速度が上がり、選択中の難易度の速度上限に達するまで加速します。
- 壁にぶつかるか自分の体を噛むとゲームオーバーです。「ワープモード」を有効にすると壁では死ななくなり、自分を噛んだ場合のみ終了します。
- 体が盤面をすべて埋めるとクリアです。
- 蛇はその場で反転できません（右に進んでいるときに「左」を押しても無効です）。素早い連続入力は順番にバッファーされ、後続のフレームで適用されるため入力が失われることはありません。

難易度はイージー / ノーマル / ハードの 3 段階でテンポを選べ、「ワープモード」は個別に有効化できます。

### 五目並べ · Gomoku

同一端末で遊ぶ 2 人対戦です。15×15 の交点、木目の盤面、星の位置、A–O / 1–15 の座標表示（非表示にも切り替え可能）を備えています。再描画は、着手・待った・ホバー・サイズ変更が発生したときだけ必要に応じて行われます。

**操作**

| 操作               | キーボード                                                | マウス / モバイル                |
| ------------------ | --------------------------------------------------------- | -------------------------------- |
| カーソル移動       | 盤面にフォーカス後 `↑` `↓` `←` `→` または `W` `A` `S` `D` | マウスホバーでプレビュー石を表示 |
| 着手               | `Enter` / `スペース`                                      | 交点をクリックまたはタップ       |
| 新規対局           | `N`                                                       | 「新規対局」ボタン               |
| 待った（元に戻す） | `U` / `Z`                                                 | 「待った」ボタン                 |
| 効果音の切り替え   | `M`                                                       | サウンドボタン                   |

**ルール**

- 黒と白が交互に交点へ石を置き、縦・横・斜めのいずれかに **5 つ以上**並べたほうが勝ちです（禁じ手はなく、長連も勝ちとして扱います）。
- 225 か所の交点がすべて埋まり、どちらも 5 つ並べられなかった場合は引き分けです。
- 最後の一手は赤い円で示されます。勝利時は並んだ石が金色でハイライトされ、勝利線が引かれます。
- 「待った」は直前の一手を取り消します。決め手を取り消した場合は、その対局の成績も併せて巻き戻されます。
- 「先手交替」を有効にすると、新規対局のたびに先手が入れ替わり、次局の色が記憶されます。

黒勝ち / 白勝ち / 引き分けの数は設定と一緒にローカルへ保存され、ワンクリックでまとめて消去できます。

### 共通の特徴

- **状態の永続化**：ハイスコア、対局成績、効果音のオン・オフ、各種設定は `localStorage` に保存され、プライベートモードなど書き込みできない環境では自動的にメモリー内保存へフォールバックします。2 つのゲームはそれぞれ別の名前空間を使うため、互いに干渉しません。
- **アクセシビリティと使い勝手**：セマンティックなマークアップ、`aria-live` による読み上げ、キーボードでフォーカスできるコントロール、`prefers-reduced-motion` への対応、タブ切り替え時の自動一時停止（スネーク）。
- **ランタイム依存ゼロ**：ネイティブの HTML / CSS / ES Modules と Canvas 2D、Web Audio だけで構成しています。

### アーキテクチャのポイント

- **ルールと表示の分離**：`src/js/core/snake-game.js` と `src/js/gomoku/gomoku-game.js` はブラウザー API に依存しないクラスです（スネークの乱数はコンストラクター引数で注入します）。そのためルールは Node.js 上で決定論的にテストできます。描画・入力・効果音・ストレージはそれぞれ独立しており、エントリーの `main.js` は組み立てと駆動だけを担当するので、ルールの変更が描画コードに波及しません。
- **2 つの駆動方式**：スネークはリアルタイムゲームで、固定ステップのアキュムレーターが `tickIntervalMs` に従ってロジックを進め、各フレームでは `alpha`（次の tick までの進捗）を使って前後の状態を補間します。これによりリフレッシュレートの異なる端末でも同じ挙動になります。五目並べは入力があったときだけ変化するためアニメーションループを持たず、必要なときに 1 フレームだけ再描画します。
- **スタイルの階層化**：`base.css` がデザイン変数と 3 ページ共通のコンポーネントを提供し、各ページのスタイルシートは `@import` で読み込んだうえで自身のレイアウトの差分だけを記述します。ビルド時に esbuild が `@import` をインライン化するため、最終的に各ページが読み込む CSS は 1 つだけになります。

## 開発用スクリプト

| コマンド               | 説明                                                                   |
| ---------------------- | ---------------------------------------------------------------------- |
| `npm run dev`          | ローカル静的サーバーを起動（既定は `127.0.0.1:5173`）                  |
| `npm run build`        | `dist/` への本番ビルド（圧縮、コンテンツハッシュ、ソースマップ）       |
| `npm run preview`      | 静的サーバーで `dist/` をプレビュー                                    |
| `npm run lint`         | ESLint によるチェック（`npm run lint:fix` で自動修正）                 |
| `npm run format:check` | Prettier のフォーマットチェック（`npm run format` で自動整形）         |
| `npm run check:assets` | 3 つのエントリーページが参照するローカル資産の存在と相対パスを検証     |
| `npm test`             | Vitest のユニットテストを実行（`npm run test:watch` はウォッチモード） |
| `npm run verify`       | 上記のチェックを順に実行。CI の中心的なステップと同等                  |

`scripts/dev-server.mjs` は `--root`、`--port`、`--host` オプションに対応しています。例：`node scripts/dev-server.mjs --root dist --port 4173`。

## テスト

テストは `tests/` にあり、Vitest を使用します（`npm test` で実行）。

- `snake-game.test.js`：初期配置、食べ物の再配置（50 個のランダムシードで蛇と重ならないことの確認を含む）、パラメーター検証、ライフサイクル、方向のバッファリングと反転の抑止、壁への衝突 / ワープ / 自分を噛む判定、「同一フレームで尾が退く」場合の合法な移動、得点、レベルと速度上限、ボーナス食べ物の出現 / 得点 / 期限切れ、盤面を埋め尽くしたときのクリア判定。
- `gomoku-game.test.js`：初期状態とパラメーター検証、手番の交替と履歴の記録、盤外や重複する着手の拒否、横 / 縦 / 2 方向の斜めの勝敗判定、隙間を埋めての 5 連、長連での勝ち、4 連は勝ちにならないこと、異なる色は連続とみなさないこと、盤面の端をまたいで並びが成立しないこと、引き分け、終局後の着手の拒否、待った（決め手を取り消した後の再開を含む）、リセット時の先手交替。
- `input-controller.test.js`（jsdom）：方向キーと `WASD` のマッピング、コマンドキー、修飾キー付き入力の無視、画面上の方向キー、スワイプとタップの操作、`detach()` 後に反応しないこと。
- `storage.test.js`：数値 / 真偽値 / 文字列の読み書きと許可リストによる検証、名前空間の分離、壊れたデータのフォールバック、`localStorage` が例外を投げる場合や利用できない場合のメモリー内保存へのフォールバック。

## GitHub Actions

- **`ci.yml` — 継続的インテグレーション**：任意のブランチへの push、すべての Pull Request、および手動実行で動作します。Node.js 20 / 22 / 24 のマトリクスで `npm ci`、ESLint、Prettier チェック、静的アセットの検証、Vitest テスト、本番ビルドを順に実行し、`dist/` 配下の 3 つのエントリーページとそれぞれのハッシュ付き JS/CSS が生成されていること、HTML が正しく書き換えられていることをページごとに検証します。さらに `.nojekyll` と favicon の存在も確認し、最後に `dist/` をアーティファクトとしてアップロードします（保持期間は 7 日）。同じブランチに新しいコミットが入ると、完了していない古い実行は自動的にキャンセルされます。
- **`deploy-pages.yml` — GitHub Pages へのデプロイ**：`main` ブランチへの push または手動実行で `dist/` をビルドして公開します。初回利用時は **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択してください。有効化するまでこの workflow は失敗しますが、CI とは独立しています。アセットの参照はすべて相対パスのため、`https://<user>.github.io/<repo>/` のようなサブパスでもサイトは正しく動作します。
- **`dependabot.yml` — 依存関係のメンテナンス**：npm の依存関係と GitHub Actions のバージョン更新を毎週チェックします。開発用依存関係の minor / patch 更新は 1 つの PR にまとめられます。

## `task-manager/` サブプロジェクト

このリポジトリには、Cloud Agent の開発環境を検証するために以前作成したフルスタックの **Task Manager**（Express + SQLite + React）も残されています。`task-manager/` ディレクトリに整理されており、独自の `package.json`、`package-lock.json`、ESLint 設定を持つ独立した npm プロジェクトです。本ゲーム集のビルド・Lint・テストには影響しません（ルートの ESLint と Prettier はいずれもこのディレクトリを無視します）。

```bash
cd task-manager
npm ci
npm run dev        # API :4000 + Web :5173
```

ゲーム集と Task Manager の Web 側を同時に動かす場合は、どちらかのポートを変更してください（例：`npm run dev -- --port 5175`）。既定ではどちらも `5173` を使用します。詳細は [`task-manager/README.md`](./task-manager/README.md) を参照してください。

## ブラウザーサポート

ES2022、Canvas 2D、`ResizeObserver`、CSS の `aspect-ratio` に対応したモダンブラウザー（Chrome / Edge 111 以降、Firefox 113 以降、Safari 16.4 以降）を対象としています。Web Audio が利用できない場合は、エラーにならず自動的に消音されます。
